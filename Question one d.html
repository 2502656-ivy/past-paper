Ways of Applying CSS Style to an HTML Document

1.INLINE CSS

Style attribute on one element.It is quick, but hard to maintain and cannot be reused.

INTERNAL CSS

Styles go in a <style> block inside the <head> of one page. It works for a single page but cannot be shared across pages

EXRERNAL CSS

Style lives in a separate .CSS file linked with . One file styles the whole site.

Recommendation -> EXTERNAL CSS

For a large multi-page government portal, External Css is preferred because one shared .CSS file style every page, so the look stays consistent and any change is made once. The browser caches the file, so pages load faster. It also separates content from presentation, so teams can work on both independently and maintenance stays easy.

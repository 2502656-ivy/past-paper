Absolute vs Relative Hyperlinks

1. Absolute Hyperlink

Uses the full web address (URL) of a page, including the protocol (https://) and the domain name. It works from anywhere because it points to one exact location.

When to use it: To link to a page outside the bank's intranet, or to a page on a different website.

Example: The bank's staff portal links to the Central Bank of Kenya website for official regulations.

Visit Central Bank of Kenya

2. Relative Hyperlink

Uses only the file path of a page, starting from the location of the current page. It does not include the domain name.

When to use it: To link between pages inside the bank's own intranet. If the intranet is moved to a new server or domain, the links keep working without being edited.

Example: The intranet home page links to the HR leave form and the loans department page, which are stored in the same website.

Apply for Leave
Loans Department

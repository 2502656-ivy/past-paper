What is the DOM?

The Document Object Model (DOM) is a tree-like representation of an HTML page that the browser creates when the page loads. Every element (heading, paragraph, div, image) becomes an object, called a node, that JavaScript can access.

How JavaScript interacts with it

JavaScript uses the DOM to find elements (for example document.getElementById()), read or change their content and style (innerHTML, style.display), and respond to events. This lets a page change without reloading.

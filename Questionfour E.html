i. Function declaration vs function expression

Function declaration

A function created with the function keyword and a name. It is hoisted, which means it can be called before the line where it is written.

Function expression

A function stored inside a variable. It is not hoisted, so it can only be used after the line where it is defined. It is often written without a name (an anonymous function).

ii. Purpose of the return statement

The return statement sends a value back to the place where the function was called and stops the function. Without it, the function gives back undefined, so the result cannot be used elsewhere in the program.
